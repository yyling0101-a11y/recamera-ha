# reCamera Installer

Install this app from the Home Assistant app store after adding
`https://github.com/yyling0101-a11y/recamera-ha` as a custom repository.
Start it once and restart Home Assistant. Add each SG2002 camera from
**Settings → Devices & Services → Add integration → reCamera**, or from the
reCamera sidebar. This installer copies the integration into `/config` and
does not flash camera firmware.
