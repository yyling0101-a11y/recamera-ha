# reCamera Installer

Start this app once, then restart Home Assistant. Under **Settings → Devices &
Services**, add the **reCamera** integration for each SG2002 device. The
reCamera sidebar provides device status, application cards and region motion
detection controls.

This app installs the HA integration. Install camera applications with
reCamera Solution. Devices can be added in HA before an application is flashed.

If HACS already manages the reCamera integration, continue using HACS; this
installer leaves that installation untouched.
